# Target Practice: small pilot

Share the deployed app link with 5–10 golfers. Include newer golfers and experienced players, and a mix of phones and computers. This is a feedback pilot before the full free-and-paid launch; accounts and payments are not connected yet. Share the website link, not the GitHub ZIP.

## Message to send with your app link

Thanks for trying Target Practice. It helps you practice choosing golf targets and understanding the tradeoff between useful distance and room for misses. We are testing whether it is useful and easy to understand. Honest confusion is valuable feedback.

Please allow about 20 minutes. Use your usual browser. Your progress is stored in that browser on that device; it will not follow you to another phone or computer automatically. My Progress lets you download a backup. Avoid clearing your browser data before backing it up.

1. Open Introduction. Then take the 10-shot assessment before trying strategy lessons. Pick a handicap profile that resembles your usual shot spread; these are illustrative training settings, not a handicap measurement. You will see the assessment feedback at the end.
2. Read the report. In your own words, what does it tell you? What would you do next?
3. Play a five-shot learning round. Retry a decision at least once. Predict what your adjustment will change before you reveal it. Open See the details if you want the numbers.
4. Try a suggested lesson, or choose one from Lessons. Tell us if its example or explanation is confusing.
5. Play a few par-3 holes. Try full screen, return Home, then Continue round. Check that you return to the same place. One person should also finish all 18 holes and review the scorecard.
6. Open My Progress and download a backup. Close and reopen the site in the same browser. Check that your progress and round are still there. Restoring a backup replaces the browser's current app data, so only test restore if you want to replace it with that copy.

There is no need to score 100 to complete the pilot. If you do, tell us whether the gold celebration feels satisfying. A good target can still produce an unlucky selected ball.

Please answer:

- Where did you hesitate or get stuck?
- What did you learn that you could use on a real course?
- Did the feedback explain why and how to improve?
- Did any recommended target seem wrong? Which hole, profile and conditions?
- Would you choose to use this again? What would make it more useful?

## Owner: before sending invitations

- Apply the complete reviewed ZIP through Work. Use the actual deployed website link.
- Open that link in a private window while signed out, or on a separate device, to verify that a tester can access and play it. Private GitHub access does not establish website access. If sign-in is requested, check the site's sharing settings before inviting people.
- Try the current build on a real phone, including touch aiming, full screen, feedback, menu and Continue round. Chromium's phone-size checks do not test iPhone Safari or Android browser UI.
- Keep a backup of your own progress before testing restore or clearing browser data.
- Start with a few testers, fix anything that stops play or loses progress, then invite the rest. Use one place for reports so repeated issues are easy to recognize.
- Prioritize lost progress or blocked play first, then misleading feedback, then usability, then visual preferences. Avoid adding features during the first pilot unless they solve a demonstrated problem.
